## Metadata input guide

|   |   |
|---|---|
|**Field**|**Preferred**|
|**Artist**<br><br>(aka: Author, Creator)|Commas or semicolons separate Names.<br><br>Avoid commas. If you enter a comma, it turns into a semicolon.<br><br>If you must use a comma, surround the name in quotes, e.g. "John Coles, Jr."<br><br>Max. characters = 64|
|**Title**|Plain text.<br><br>Separate parts with semicolons.<br><br>Max. characters = 64|
|**Description**<br><br>(aka: Caption)|Plain text.<br><br>Separate parts with semicolons.<br><br>Max. characters = 2000|
|**Keywords**<br><br>(aka: Tags)|Commas or semicolons separate Keywords.<br><br>Avoid commas. If you enter a comma, it turns into a semicolon.<br><br>Max. characters = 64 per keyword. Unlimited number of keywords.|
|**Copyright Notice**<br><br>(aka: Copyright)|Plain text.<br><br>Separate parts with semicolons.<br><br>Max. characters = 128|
