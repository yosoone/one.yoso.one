Here is a comprehensive list of countries created (i.e., that declared or gained independence) after September 6, 1973, organized chronologically:

🗓️ 1973

```
•	Guinea-Bissau — September 24, 1973 (unilaterally declared independence from Portugal; formally recognized by Portugal on September 10, 1974) ￼
```

🗓️ 1974

```
•	Grenada — February 7, 1974 (from the UK) ￼
•	Niue — October 19, 1974 (became a self-governing parliamentary government in free association with New Zealand) ￼
```

🗓️ 1975

```
•	Mozambique — June 25, 1975 (from Portugal)
•	Cape Verde — July 5, 1975 (from Portugal)
•	Comoros — July 6, 1975 (from France)
•	São Tomé and Príncipe — July 12, 1975 (from Portugal) ￼
•	Papua New Guinea — September 16, 1975 (from the UK)
•	Angola — November 11, 1975 (from Portugal)
•	Suriname — November 25, 1975 (from the Netherlands) ￼
```

🗓️ 1976

```
•	Seychelles — June 29, 1976
•	Western Sahara (Sahrawi Arab Democratic Republic) — February 27, 1976 (partially unrecognized) ￼
```

🗓️ 1977

```
•	Djibouti — June 27, 1977 ￼
```

🗓️ 1978

```
•	Dominica — November 3, 1978
•	Solomon Islands — July 7, 1978
•	Tuvalu — October 1, 1978 ￼
```

🗓️ 1979

```
•	Kiribati — July 12, 1979
•	Saint Lucia — February 22, 1979
•	Saint Vincent and the Grenadines — October 27, 1979 ￼
```

🗓 1980

```
•	Vanuatu — July 7, 1980

```

🗓️ 1981

```
•	Belize — September 21, 1981
•	Antigua and Barbuda — November 1, 1981 ￼
```

🗓️ 1983

```
•	Saint Kitts and Nevis — September 19, 1983 ￼
```

🗓️ 1984

```
•	Brunei — January 1, 1984 ￼
```

🗓️ 1990

```
•	Namibia — March 21, 1990 ￼
```

🗓️ 1991 (Dissolution of the Soviet Union)

```
•	Lithuania, Latvia, Estonia, Ukraine, Belarus, Moldova, Georgia, Armenia, Azerbaijan, Uzbekistan, Turkmenistan, Tajikistan, Kyrgyzstan, Kazakhstan — all declared independence from Soviet rule between March and December 1991 ￼
•	Slovenia and Croatia — June 25, 1991 (from Yugoslavia)
•	North Macedonia — September 17, 1991 (from Yugoslavia) ￼
```

🗓️ 1992

```
•	Bosnia and Herzegovina — March 6, 1992 (from Yugoslavia) ￼
```

🗓️ 1994

```
•	Palau — October 1, 1994 (from US trusteeship)
```

🗓️ 2002

```
•	East Timor (Timor-Leste) — May 20, 2002 (from Indonesia/UN administration)
```

🗓️ 2006
